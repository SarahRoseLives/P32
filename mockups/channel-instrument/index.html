The screen is not a touch target; these controls only drive the mockup.

THE IDEA

One instrument, three channel families. The radio keeps the same frame and changes the object being operated: a conventional channel, a trunked system's talkgroup, or an analog frequency.

* profile OK channels HOLD OK program PTT talk

CHANNEL MODEL

  • Conventional frequency + NAC + TG; direct PTT, no control channel.
  • Trunked system + talkgroup; CC affiliation and grants; unit from the system.
  • Analog frequency + tone + bandwidth; the existing FM path.
  • FPP edits all three locally; write is explicit and summarized.

CONSTRAINTS

  • 240 × 320, 16 colors, 4 bpp; no gradients or shadows inside the screen.
  • No touch. Encoder moves focus; OK edits; BACK saves/returns.
  • PTT remains physical and is never a touch target.
  • Long OK enters local programming; short OK opens the channel sheet.
