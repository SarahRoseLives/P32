# p32firmware.com

The P32Firmware site and web flasher are generated by `site/` and served by a small Go binary. The build defaults to
the P32Firmware name, the p32firmware.com domain, the P32Firmware tagline and the P25 codeplug editor.

```
# Put the P25 release image in build/dist first, then:
RFOUNDRY_PYTHON=/path/to/venv/bin/python web/tools/build.sh
web/build/p32firmware-web -dev :8080
```

The P25 codeplug editor is at `/codeplug/` and linked from the navigation. It edits channels, zones and the P25 systems
in the radio's settings. `RFOUNDRY_NO_CODEPLUG=1 web/tools/build.sh` builds the coming-soon page instead, for a test
build.

The server embeds `web/site`, terminates TLS with Let's Encrypt for `p32firmware.com`, redirects `www`, and accepts the
flasher's optional `/v1/` reports under `/var/lib/p32firmware/reports/`. Deploy with `deploy/deploy.sh`; it uses the
`P32Firmware` sshm server and opens ports 80/443.
